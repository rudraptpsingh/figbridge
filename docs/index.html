How it works

Three processes, one localhost port.

The plugin runs inside Figma. The bridge runs on your machine. Your agent connects via stdio MCP. Nothing leaves 127.0.0.1 unless you make it leave.

Plugin side
Pushes payloads on selection-change, answers commands over SSE, runs inside Figma's sandbox with documentAccess: "dynamic-page".
Bridge side
Tiny Node server. HTTP for the plugin, stdio for the MCP client. Command queue with UUID + Promise + timeout. Persists the last 25 payloads to ~/.figbridge/.
Agent side
Any MCP client launches figbridge-mcp as a subprocess. Tools appear alongside your other MCP servers. No API keys, no auth.
The API surface

17 MCP tools, grouped by job.

Every tool runs through the plugin — no REST, no PAT, no Figma account required.

Read

  • get_current_selectionHTML / CSS / Tailwind / tokens for the current selection.
  • get_last_exportAlias. Last pushed payload.
  • list_historyRecent selections, newest first.
  • get_tokensTokens + CSS vars + Tailwind config.
  • bridge_statusHealth + plugin-connected status.
  • diff_sinceHistory entries after a timestamp, with SHA-1 fingerprints.

Catalog

  • list_screensAll top-level frames, categorized (splash, auth, home, …).
  • list_componentsComponents + sets with variants.
  • describe_screenSemantic summary — size, bg, text, components used.
  • export_app_specOne-shot JSON spec of the whole file + flows.
  • list_assetsBase64 SVG/PNG dump of icons, images, illustrations.
  • select_nodeSelect & scroll to a node by id or name.
  • export_nodeExport a specific node without a user click.

Write & Lint

  • clone_screenDuplicate a frame; optional per-TEXT replacements.
  • recolorSwap hex colors across selection / page / file.
  • apply_tokensBind loose fills to matching local color variables.
  • lint_dsUnbound colors · non-grid spacing · orphans · dup names.

Setup

Four steps. Under a minute.

One command patches Claude Desktop. One menu click loads the plugin. You own the whole stack.

1

Run the installer

npx figbridge-mcp init
Patches your Claude Desktop config. No globals, no sudo.

2

Import the plugin

In Figma: Plugins → Development → Import plugin from manifest… and pick plugin/manifest.json.

3

Toggle Live bridge

Run Figbridge and flip the Live bridge switch on. Green dot = connected.

4

Restart Claude

Quit & reopen Claude Desktop. Ask: "what tools does figbridge expose?" — you should see 17.

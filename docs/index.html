What you can do, today

Every flow below runs against your real Figma file, driven by natural-language prompts to Claude.

Flow 1 · Spec to app

"Ship the whole app from this Figma file."

One tool call returns every screen, every component variant, tokens, CSS vars, and Tailwind config. Claude writes the Next.js project.

Use export_app_spec. Scaffold a Next.js + Tailwind app with one route per screen, grouped by category. Got the full catalog: 37 screens, 43 components, 35 color tokens. Writing app/(onboarding)/splash, app/(auth)/sign-in, tailwind.config.js…
Flow 2 · Rebrand

"Flip the brand color across the whole file."

recolor swaps hex-to-hex file-wide. apply_tokens binds loose fills to variables so the next swap is a one-line change.

Recolor #ff7a29 → #3ddc97 file-wide, then bind loose fills to variables. Recolored 9 fills across 58 nodes. Bound 14 layers to --color-brand-primary, 1 remaining unbound.
Flow 3 · Design review

"Lint the file for DS violations."

The /design-review slash command ships with Figbridge. Unbound colors, off-grid spacing, orphan components, dup names — PR-ready markdown.

/design-review 500+ findings across 3 rules — unbound-color, non-grid-spacing, orphan-component. Reply "fix bindings" to run apply_tokens.
Flow 4 · Asset dump

"Export every icon into my repo."

list_assets kind:icon returns base64 SVGs. Claude decodes and writes them to src/icons/ using node names.

Export all icons as SVG and write them to src/icons/. Exported 24 icons. Wrote src/icons/home.svg, src/icons/scripts.svg, … sizes 311B–814B.
Flow 5 · Translate

"Ship a JA version of the onboarding flow."

clone_screen with textReplacements duplicates frames and swaps strings — fonts auto-loaded.

Clone every screen tagged onboarding and translate text EN → JA using this glossary. Cloned 5 screens, applied 42 replacements. New frames placed at +1600px to the right.
Flow 6 · Pair-design

"Fix a11y on whatever I'm selecting."

Live bridge auto-pushes on every selection. Claude sees what you see, suggests fixes, offers to clone-with-fix so you can diff side-by-side.

Rewrite this hierarchy for a11y, clone with the fix. H2 demoted to H3, CTA contrast 3.1 → 7.2, cloned as "S09 Splash (a11y)".

Install

One command wires Claude Desktop. One menu click loads the plugin. You own the whole stack.

  1. Run the installer: npx figbridge-mcp init
    Patches ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) or the Windows equivalent. No globals, no sudo.
  2. Load the plugin in Figma: Plugins → Development → Import plugin from manifest… → figbridge/plugin/manifest.json
  3. Run Figbridge, toggle Live bridge on (green dot).
  4. Restart Claude Desktop. Ask "what tools does figbridge expose?" — you should see 17.
Runs on localhost:7331. Everything stays on your machine. Source: github.com/rudraptpsingh/figbridge.

17 MCP tools

Read, write, catalog, and diff. Every tool below is plugin-only — no Figma REST, no PAT.

list_componentsComponents & component sets with variants.
describe_screenSemantic description — size, background, text, components, one-paragraph summary.
export_app_specOne-shot JSON spec of the whole file — screens, components, tokens, flows.

recolorSwap SOLID fill/stroke hex colors across selection / page / file.
apply_tokensBind loose fills to matching local color variables.
